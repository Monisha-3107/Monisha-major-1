# Data Visualization Project (Housing Data)

## Description

This project analyzes housing data using Python. It focuses on understanding price distribution and how different features like AC, parking, and area affect house prices.

## Features

* Price range distribution visualization
* Comparison of AC vs Non-AC house prices
* Parking availability vs house price analysis
* Price gap analysis based on area and preferred location

## Technologies Used

* Python
* Pandas
* Matplotlib

## Files

* House analysis.py – Main Python script
* housing.csv – Dataset file

## How to Run

1. Install required libraries:
pip install pandas matplotlib
2. Run the program:
python analysis.py

## Output

* Line chart for price distribution
* Bar charts for comparisons
* Console output for price gap
